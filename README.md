# Ouinon

Suivi de vie minimaliste : chaque question arrive en notification à son
heure, on répond avec 2 ou 3 boutons sans ouvrir l'appli, et l'appli
croise les réponses pour montrer ce qui va avec quoi. Tout reste sur le
téléphone. Appli Flutter, Android d'abord.

## Documentation

- `docs/reprendre_le_projet.md` : **à lire en premier** pour reprendre le
  projet (état, choix de Paul, outils, comment fabriquer un APK).
- `docs/plan_action.md` : étapes et prochaines actions.
- `docs/historique.md` : décisions et versions, dans l'ordre.
- `docs/revue_produit.md` : les choix produit de Paul.
- `docs/fonctionnement.md` : comment l'appli est construite.
- `CLAUDE.md` : consignes pour Claude.
